# U0001F393 منصة X التعليمية — ManasaX

**منصة تعليمية جزائرية مجانية بالكامل** لتلاميذ الطورين المتوسط والثانوي: دروس وملخصات وقوانين وتمارين وفروض واختبارات تفاعلية، تعمل كموقع ويب وكتطبيق (PWA) يثبّت على الهاتف ويعمل بلا إنترنت.

## ✨ الميزات

- U0001F4DA **دروس شاملة** في الرياضيات والعلوم الفيزيائية وفق منهاج الجزائر: أنشطة، تذكيرات، قوانين، أمثلة محلولة، تمارين مع الحلول المفصلة
- U0001F9EE **قوانين مصيّرة بجودة عالية** (KaTeX) مع بديل مقروء نطيف يعمل دائمًا حتى بلا إنترنت — لا كود خام أبدًا
- U0001F3AF **اختبارات تفاعلية** بنتيجة فورية وتوضيح لكل إجابة
- U0001F4CA **متابعة التقدم**: الدروس المكتملة، النتائج، المحفوظات للمراجعة، خريطة المحاور
- U0001F319 **وضع داكن/فاتح** + معرض 24 خلفية + خلفيات من معرض هاتفك + ضبط حجم النص والكثافة والتباين
- U0001F510 **مصادقة آمنة**: دخول بالبريد ورمز تحقق مؤقت — لا نجمع كلمات المرور إطلاقًا
- U0001F514 إشعارات وإعلانات داخل المنصة + مكتبة ملفات PDF + مكتبة فيديو
- U0001F4F1 **تطبيق أندرويد (PWA)** يعمل بلا إنترنت ويُحدّث تلقائيًا من جذر المستودى

- HTML / CSS / JavaScript (ES5) بلا أي إطار عمل — ملف `index.html` واحد يعمل كتطبيق PWA
- `Service Worker` للتخزين المؤقت والعمل بلا إنترنت
