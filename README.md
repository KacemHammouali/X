## ✨ أبرز المزايا

- 📚 **محتوى منهاجي كامل**: الرياضيات والفيزياء (وفي التوسع المستمر) بتنظيم دقيق: محاور، دروس، خلاصات «أهم ما يجب أن تتذكره»، وقوانين مرسومة كمعادلات حقيقية.
- 🔐 **حسابات آمنة**: تسجيل بالبريد مع رمز تحقق سري، ومزامنة التقدم مع الجهاز — تفتح من أي هاتف فتجد تقدمك كاملًا.
- 📴 **عمل كامل بلا إنترنت**: بعد أول زيارة تعمل كل الدروس والاختبارات من دون شبكة.
- 📨 **إشعارات فورية** للإعلانات والتوجيهات، بموافقة صريحة وقابلة للإيقاف في أي لحظة.
- 🧪 **اختبارات تفاعلية** بتصحيح فوري وشرح لكل جواب، مع تتبع دقيق للتقدم.
- 🌙 **وضع ليلي/نهاري** متوازن، وواجهة عربية RTL كاملة بتصميم حديث مقاس بدقة على الهاتف والكمبيوتر.
- 📱 **تطبيق PWA/APK** بملء الشاشة، يُبنى من الموقع نفسه من دون أي كود إضافي.

## 🚀 التشغيل والنشر

الموقع صفحة واحدة خالصة (SPA) بلا أي خادم:

1. ارفع الملفات كلها إلى جذر الفرع الرئيسي `main` ثم Commit.
2. من **Settings → Pages → Branch: main** فعّل GitHub Pages.
3. الموقع يعمل خلال دقائق، والتطبيق المثبت يعرض زر «تحديث الآن» تلقائيًا عند صدور إصدار جديد.

## 📱 تحويل المنصة إلى تطبيق APK

عبر [PWABuilder](https://www.pwabuilder.com): الصق رابط الموقع ← Analyze ← بطاقة Android ← خيارات:
- **Display mode: Fullscreen** (إخفاء شريطي أندرويد العلوي والسفلي)
- **Package ID**: ثابت لا يتغير (`com.xhak.manasax`)
- **مفتاح التوقيع**: يُستعمل المفتاح المحفوظ نفسه لكل تحديث (`Use mine`) حتى يثبّت التطبيق فوق القديم بلا إزالة — ومع بصمته يُنشر ملف `assetlinks.json` في `.well-known/` بمستودع الصفحة الرئيسية ليربط التطبيق بالموقع.
- ثم رفع `X.apk` الجديد إلى جذر هذا المستودع.
