الميزات
- 📱 تطبيق قابل للتثبيت (PWA): أيقونة على الشاشة الرئيسية، ملء الشاشة، وعمل كامل بلا إنترنت بعد أول زيارة.
- 🌐 صفحة واحدة خفيفة: كل شيء في index.html واحد — تحميل فوري حتى على شبكات ضعيفة.
- 📨 تواصل مضمون مع المالك: رسالة واحدة لكل زائر كل 24 ساعة عبر قناتين فوريتين متنوبتين على الحصص الشهرية (250 ثم 200 رسالة/شهر) مع عدّ تنازلي حي وإعادة تلقائية للعد في مطلع كل شهر.
- 🧪 بنك أسئلة تفاعلي: اختبارات لكل محور مع تصحيح فوري وشرح لكل جواب.
- 📊 تتبّع التقدم: حفظ النتائج والإنجاز على جهاز الطالب نفسه.
- 🌙 وضع ليلي/نهاري وواجهة عربية RTL بالكامل.

النشر على GitHub Pages
 1. ارفع الملفات السبعة كلها معًا إلى جذر الفرع الرئيسي للمستودع.
 2. من إعدادات المستودع: Settings → Pages → Branch: main ثم حفظ.
 3. الموقع يعمل خلال دقائق على https://<اسم-المستودع>.github.io/.
تحويل المنصة إلى تطبيق APK
أسهل طريق: افتح PWABuilder والصق رابط المنصة — يولّد لك حزمة Android (APK/AAB) جاهزة للنشر على Google Play من نفس الموقع، بدون أي كود إضافي. (لبعض المتطلبات قد يطلب أيقونة PNG بدل SVG: صدّر icon.svg إلى PNG 512×512 من أي محول، وأضف سطريها في manifest.json.)
