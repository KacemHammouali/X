# 🎓 منصة X التعليمية — ManasaX

**منصة تعليمية جزائرية مجانية بالكامل** لتلاميذ الطورين المتوسط والثانوي: دروس وملخصات وقوانين وتمارين وفروض واختبارات تفاعلية، تعمل كموقع ويب وكتطبيق (PWA) يثبّت على الهاتف ويعمل بلا إنترنت.

## ✨ الميزات

- 📚 **دروس شاملة** في الرياضيات والعلوم الفيزيائية وفق منهاج الجزائر: أنشطة، تذكيرات، قوانين، أمثلة محلولة، تمارين مع الحلول المفصلة
- 🧮 **قوانين مصيّرة بجودة عالية** (KaTeX) — المكتبة مضمّنة داخل التطبيق فتعمل دائمًا حتى بلا إنترنت، مع بديل مقروء نظيف لأي حالة نادرة: لا كود خام أبدًا
- 🎯 **اختبارات تفاعلية** بنتيجة فورية وتوضيح لكل إجابة
- 📊 **متابعة التقدم**: الدروس المكتملة، النتائج، المحفوظات للمراجعة، خريطة المحاور
- 🌙 **وضع داكن/فاتح** + معرض 24 خلفية + خلفيات من معرض هاتفك + ضبط حجم النص والكثافة والتباين
- 🔒 **مصادقة آمنة**: دخول بالبريد ورمز تحقق مؤقت — لا نجمع كلمات المرور إطلاقًا
- 🔔 إشعارات وإعلانات داخل المنصة + مكتبة ملفات PDF + مكتبة فيديو
- 📱 **تطبيق أندرويد (PWA)** يعمل بلا إنترنت ويُحدّث تلقائيًا من جذر المستودع

## 🌐 الروابط

- الموقع: <https://kacemhammouali.github.io/X/>
- تحميل التطبيق (APK): <https://kacemhammouali.github.io/X/X.apk>

## 🛠️ التقنية

- HTML / CSS / JavaScript (ES5) بلا أي إطار عمل — ملف `index.html` واحد يعمل كتطبيق PWA
- KaTeX **مضمّنة داخل الملف** (CSS + JS + auto-render) — المعادلات تُرسم بلا إنترنت وبلا أي خادم خارجي
- `Service Worker` للتخزين المؤقت والعمل بلا إنترنت
- مصادقة بالبريد ورمز تحقق (Supabase) + نموذج محلي بالكامل بلا خادم
- تحديثات عن بُعد عبر `versions.json` دون إعادة النشر على المتصفح

## 🔐 الخصوصية (خلاصة)

نجمع الحد الأدنى لتشغيل حسابك وتقدمك، ولا نجمع كلمات المرور، ولا نشارك بياناتك مع أي طرف ثالث. التفاصيل الكاملة (مدة الاحتفاظ، مكان التخزين، حقوق الحذف) داخل المنصة: الإعدادات ← الخصوصية والأمان ← سياسة الخصوصية.
